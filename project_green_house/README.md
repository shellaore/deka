# ЗелёныйДом — лендинг

Статический сайт, без сборки и зависимостей. Открывается напрямую в браузере.

## Структура

```
index.html    — разметка страницы
styles.css    — все стили (тема «Свежий»: зелёный + лайм-акцент)
script.js     — интерактив: фильтры каталога, корзина, переключатель
                размера коробки, FAQ-аккордеон, форма подписки
```

## Запуск локально

Просто открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Данные

Тексты товаров, тарифов, FAQ, шагов и болей ЦА захардкожены в начале
`script.js` в виде массивов (`PRODUCTS`, `PLANS`, `FAQS`, `STEPS`, `PAINS`,
`BENEFITS`) — их удобно редактировать или вынести в JSON/CMS позже.

## Шрифты

Google Fonts: Spectral (заголовки) и Golos Text (текст интерфейса),
подключены через `<link>` в `index.html`.
